VybeTop holders

Holder concentration for one mint

Enter a mint and this page ranks wallets by the share of supply they hold, with top 10 and top 100 concentration. The first page can include up to a thousand holder rows, each with its share of supply.

Sort the holder list and export it. Labeled owners are called out from the holder rows, separate from wallets with no name. A free API key on Vybe is enough to start. Paid plans raise the rate limit.

Generate a free API key to get started

Endpoints Used:

  • Top Token Holders API GET /v4/tokens/{mintAddress}/top-holders
  • Token Details API GET /v4/tokens/{mintAddress}
  • Historical Trades API GET /v4/trades
  • Labeled Programs API GET /v4/programs/labeled-program-accounts
  • Top Token Traders API GET /v4/wallets/top-traders

  • Supply share

    Each row is a wallet and the percent of supply it holds.

  • Concentration

    Top 10 and top 100 shares are summed from the holder list.

  • Labeled owners

    Known owner names on the holder rows are split out from plain wallets.

  • Sort and export

    Sort the list by supply share and export the rows you loaded.

Supply Concentration (Fetched Cohort)

Each row’s % of circulating supply comes from the API. The bars are running sums of those percentages for the top k ranks (after your sort). Anything not in your fetched list is simply the rest of circulation—the same idea as comparing the token’s circulating total to the balances you see in the table.

Histograms count fetched rows by holder % band and USD band (not the full chain). The right column lists the top labeled entity groups by combined supply for this fetch.
